SISTEMA DE GERENCIAMENTO ACADÊMICO - AULA 10

Como executar:
1. Extraia a pasta sistema-academico-aula10.
2. Abra index.html no navegador (recomendado: usar Live Server no VS Code).
3. Navegue pelo menu.

Estrutura:
- index.html: Dashboard
- alunos.html / aluno-form.html: listagem, busca, filtro, detalhes, cadastro e remoção de alunos
- cursos.html / curso-form.html: listagem e cadastro de cursos
- matriculas.html / matricula-form.html: listagem e cadastro de matrículas
- usuarios.html / usuario-form.html: listagem e cadastro de usuários
- css/style.css: estilos
- js/dados.js: arrays de dados iniciais
- js/app.js: DOM, eventos e funções da Aula 10

IMPORTANTE:
Esta atividade ainda NÃO utiliza LocalStorage nem banco de dados.
Os dados são mantidos em arrays JavaScript na memória. Ao recarregar ou abrir outra página,
os cadastros feitos durante a navegação podem ser perdidos. Isso está de acordo com a orientação
da atividade de não utilizar LocalStorage nesta aula.

Observação:
O projeto foi montado com base nos arquivos aluno-form.html e alunos.html enviados.
Os demais arquivos foram completados para atender à estrutura solicitada na atividade.
